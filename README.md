# Bacterial Whole Genome Analysis Pipeline

This repository contains a Linux-based workflow for bacterial whole genome sequence analysis.

## Workflow

1. Quality control
2. Genome assembly
3. Annotation
4. AMR gene detection
5. Virulence factor detection
6. Mobile genetic elements
7. Plasmid identification
8. Pan-genome analysis

## Software

FastQC
Trimmomatic
SPAdes
Prokka
ABRicate
AMRFinder
